# Ravindu Wanasinghe portfolio

This repository publishes the static Next.js portfolio at https://ravinduwanasinghe0524.github.io/.

The editable source is at https://github.com/RavinduWanasinghe0524/Portfolio-next. Build it with `npm run build`, then copy the generated `out/` files to this repository root. Keep `.nojekyll` so GitHub Pages serves the `_next/` assets.
